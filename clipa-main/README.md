# Clipa

A modern clipboard manager with split/merge functionality and Khmer language support.

## Features

- **Auto-Paste**: Automatically paste clipboard content
- **Split/Merge**: Split text by separators or merge lines with custom separators
- **History**: Track all clipboard items
- **Pinned Items**: Pin frequently used clipboard items
- **Undo/Redo**: Undo and redo text operations
- **Modern UI**: Dark theme with smooth interactions

## Installation

1. Install Python 3.8 or higher
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

## Running the App

```
python main.py
```

## Building EXE

```
python build_exe.py
```

The executable will be in the `dist` folder.

## Usage

- Double-click history items to copy them
- Right-click history items to pin them
- Use Split to break text by separators
- Use Merge to join lines with separators
- Select separator type from dropdown or use custom
